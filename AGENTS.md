# Course routing instructions

Apply these instructions when the user asks to start, take, continue, resume, or
walk through **Introduction to the Language Model Evaluation Harness**.

1. Read `CODEX_INSTRUCTOR.md` and follow it as the teaching contract.
2. Create `course-progress.md` from `COURSE_PROGRESS_TEMPLATE.md` if it does not
   exist, then read it before selecting the next checkpoint.
3. Use `answer-key/README.md` to assess responses and choose hints. Do not reveal
   an answer before the learner attempts the question unless they explicitly ask
   for the answer.
4. Teach one concept and ask one question at a time. Wait for the learner's
   response before advancing.
5. Preserve the course's strict AI Product Manager framing. Connect mechanics to
   product decisions, claims, risks, and evidence.
6. Never run the final holdout as part of tutoring or routine setup.

For ordinary repository maintenance or contributions, use the repository's
normal files and tests; the Socratic course flow applies only when the user is
taking the lesson.
